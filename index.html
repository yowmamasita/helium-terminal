Helium Terminal

A tiny macOS terminal for running coding agents. It's built on libghostty with native Swift and AppKit, and the whole app is 15 MB.

Install · GitHub

When Claude Code, Codex and a few dev servers run side by side, the sidebar tells you where to look. Every tab shows its title, folder and listening ports, and the strip above the terminal shows the git branch, how far it's ahead or behind, and whether there are uncommitted changes. A pane blocked on a permission prompt or an approval request lights up orange, and so does its tab, until you answer it. Everything else gets a quiet green ring that clears when you look at it.

Press Cmd+Q and Helium brings your tabs, splits and folders back next time, and resumes every Claude Code and Codex conversation with the flags it was started with. Tabs go into Chrome-style groups that collapse, take colored labels, and get their own name with a double-click. Every tab splits horizontally and vertically.

The helium command and a local socket open tabs, split panes, type into them and send notifications. Every pane knows its own ID through $HELIUM_PANE, so an agent hook rings the right one.

Fonts, themes and keybinds come from your Ghostty config as is. Settings covers the common options and lists all 600+ of Ghostty's with their docs. Hidden tabs and covered windows stop rendering and give their GPU memory back. Updates come from GitHub releases, and Helium only installs a build signed by the same developer and notarized by Apple. It never restarts on its own.

It runs on Apple Silicon with macOS 13 or later. Both of these install the app and the helium command.
