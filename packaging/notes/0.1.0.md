First release.

- A sidebar of vertical tabs showing the title, git branch, working directory, listening ports and the latest notification
- A notification ring on a pane when a program needs you (OSC 9/777 notifications, the bell, or `helium notify`)
- Horizontal and vertical splits in every tab
- The `helium` CLI and a Unix socket API for scripting
- Rendering by libghostty (Metal), configured from your Ghostty config
- A native Swift/AppKit app: a 12 MB download, about 60 MB in the background

Apple Silicon only, macOS 13 or later. Signed and notarized.

```sh
brew install --cask yowmamasita/tap/helium-terminal   # Homebrew
zb install yowmamasita/tap/helium-terminal            # zerobrew
```
