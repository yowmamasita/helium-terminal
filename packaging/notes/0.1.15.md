- Queued prompts: queue a prompt for a coding agent while it's busy and Helium sends it when the turn ends, one prompt per turn. Press ⌘⇧M (Edit > Queue Prompt for Agent), right-click a tab, or run `helium queue`. The pane shows its queue at the bottom right, where you can edit or cancel prompts, and the tab shows the count. A queued prompt is never typed into a shell or a permission prompt. Tested with Claude Code and Codex; other agents follow from the status they report (see the README).
- `helium read` prints a pane's screen, or its whole history with `--scrollback`.
- `helium wait` blocks until a pane's agent is idle or needs you, and `helium list` reports each pane's agent and whether it is working, blocked or idle.
- `helium key` presses keys by name (`esc`, `down`, `enter`, `ctrl+c`, `shift+tab`).
- New tab commands: `close-tab`, `rename`, `label`, `group`, and `clear` for a pane's ring. `helium split` takes `left`, `up`, `--cwd` and `--command`.
